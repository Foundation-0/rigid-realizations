# G160 source replay

The [primary paper, section 4.2](https://arxiv.org/html/1811.12800v1#S4.SS2) gives the 18 lengths used for its reported 132-realization construction. The input file records the printed decimals exactly and flags the need for independent transcription.

The first triangle is pinned using edges 1-2, 1-3 and 2-3. Its square-root coordinate is enclosed rather than rounded to a point. The frame builder proves only those coordinate bounds. It does not isolate or count any realization. Candidate roots and a separate spatial interval checker are still required.
